# .NET System Monitor

A lightweight Windows desktop system monitor that plots **CPU**, **Memory**, and **Network**
usage as a live line graph, with per-core CPU, memory pie, and disk space views.

<img width="269" height="192" alt="Screenshot 2026-11-08 134846" src="https://github.com/user-attachments/assets/4fb55681-7195-42ac-bef8-99248352c555" />

## Download & run

- Download `Monitor.exe` and run it — no installation required.
- Requires Windows with .NET Framework 4.8 (included in Windows 10/11).

## Features

- Live CPU / Memory / Network graphs.
- Per-core CPU bar chart, memory pie chart, and disk space table (Tools menu).
- Colors, refresh rate, network bandwidth, and left-to-right options.
- Settings persist to `%APPDATA%\Monitor\monitorinfo.json`.
